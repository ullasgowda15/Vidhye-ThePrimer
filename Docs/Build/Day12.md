## 1. Yesterday's expected end state
Interest graph steers personalized worlds/characters; recurring characters + `WorldPlace` map persist; ≥3 world palettes; fear ceiling respected; consistency + memory intact. Every child gets a visibly different world. No parent‑facing surfaces yet.

## 2. Today's goal (one sentence)
Give the parent **visible value and total transparency**: honest per‑session and weekly reports, plain‑language learning insights mapped to milestones, and a transparency log where they can read exactly what their child experienced.

## 3. Why this scope
The parent's surface converts trial → subscription → multi‑year renewal (§12). Transparency is the headline trust feature — the unique answer to "what is it saying to my child?" (§12.6). Reports must be **honest and specific**, never inflated or fabricated (§12.1, §13.9).

## 4. Tasks by workstream

### 4.1 Backend — report generation (Celery) + endpoints
```
GET /api/v1/children/{id}/reports/session/{sessionId} -> SessionReport
GET /api/v1/children/{id}/reports/weekly              -> WeeklyReport   (shape per §18.7)
GET /api/v1/children/{id}/memories                    -> [Memory]       (parent transparency)
GET /api/v1/children/{id}/progress                    -> [{domain, objective, mastery, status}]
GET /api/v1/adventures/{id}/transcript                -> verbatim beats  (owner-scoped)
```
- **SessionReport** (§12.1): where they went, the key choice, the objective exercised + how it went, and one **specific human highlight** ("Aarav named the dragon 'Sparkle' and chose to help it — early empathy."). Generated by a Celery task post‑session.
- **WeeklyReport** (§18.7 shape): `{week, sessions, completionRate, highlight, skills[], milestone?, interests_trend[], recommendation}`.
- **Milestone rollup** (§10.6): objectives → milestones in plain language.

### 4.2 AI — summary prompt (§12.1, §13.9)
- Honest, specific, warm; celebrates a **real** moment; never hypes. **Grounded strictly in actual session data** — pass the real beats/choices/mastery deltas; forbid invention. If nothing notable happened, say so plainly rather than inflating.

### 4.3 Frontend — parent dashboard (§12.10)
- `src/routes/parent/`: `Home.tsx` (today's highlight + quick controls), `SessionReport.tsx`, `WeeklyReport.tsx`, `Insights.tsx` (per‑domain, plain language, milestone‑mapped — **no grades/percentiles**, §12.3), `Transparency.tsx` (read the child's **actual** stories verbatim). Calm theme (§15).
- IA per §12.10 (Home → Reports / Weekly‑Growth / Insights / Transparency / Settings / Privacy / Billing / Children).

## 5. Key stubs
- `apps/analytics/reports.py::generate_session_report(session)` + `generate_weekly_report(child, week)`.
- Insights framed developmentally/positively; status labels like "emerging / practicing / mastered", never a percentile.

## 6. Do NOT do today
- ❌ No billing. ❌ No settings/controls (Day 13). ❌ Do NOT inflate or fabricate report content — honesty **is** the product. ❌ No child‑facing changes. ❌ Do NOT expose another family's data (owner‑scope everything).

## 7. Acceptance criteria (done when ALL true)
1. A per‑session report generates after a session: specific, honest, with a **real** highlight (not generic boilerplate).
2. A weekly report aggregates sessions/completion/skills/milestone/interest‑trend/recommendation, matching the §18.7 shape.
3. Learning insights render per‑domain in plain language mapped to milestones — **no grades/percentiles**.
4. The transparency log shows the child's **actual** stories verbatim; owner‑scoped (parent B cannot read parent A's child).
5. Report content is grounded in real session data (spot‑check several claims against what actually happened — **no fabrication**).
6. Parent dashboard IA + calm theme render correctly across the pages.
7. `make lint && make test` + **CI green**.

## 8. Founder manual test
Play a couple of sessions as a child, then open the parent dashboard: read the session + weekly report — are they specific and **true**? Open the transparency log and read the actual story your child played. Confirm insights feel supportive, not like a report card. Try (with a second account) to read the first child's data → blocked.

## 9. End state to hand to Day 13
Parents get honest, specific session + weekly reports, milestone‑mapped plain‑language insights, and a verbatim transparency log — all owner‑scoped and grounded in real data. The parent can see and trust the value. No settings/controls or privacy center yet.
